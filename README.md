# ナニコレ!? AIクイズショー

りんか・さくら・ママの3人で遊べる、撮影向けの「何と何が合体した？」クイズです。音は鳴りません。

## 遊び方

このリポジトリをダウンロードし、`dist/index.html` を Chrome または Edge で開いてください。インターネット接続やインストールは不要です。詳しい進行方法は [`dist/遊び方.txt`](dist/遊び方.txt) にあります。

- 30問の画像から毎回10問をランダムに出題します。
- 画像は3段階で公開。ヒント1で正解なら3点、ヒント2なら2点、全体公開なら1点です。最終問題は得点2倍です。
- 同時に正解した人は、各人の名前カードを押して全員に加点できます。
- 3問ごとに、30種類からランダムに選んだ「なんやねん休憩」が入ります。面白かった人には複数人でも各+1点を付けられます。
- 途中でも右上の「最初から」から新しい10問で遊び直せます。

## 操作

| 操作 | 内容 |
| --- | --- |
| 名前カードをクリック | その人に現在のヒントの得点を加算 |
| `Space` | 次のヒント・次の問題へ進む |
| `A` | 答えを公開 |
| `U` | 1つ前の操作に戻す |
| `R` | 撮影表示を切り替える |
| `F` | 全画面表示を切り替える |

## ファイル

- `dist/`: そのまま遊べるWebページ、問題画像、日本語フォント
- `image-prompts.json`: 問題画像の制作プロンプト
- `test-game.cjs`: 得点・進行・抽選の動作チェック
- `package.py`: オフライン配布用ZIPの作成

テストは `node test-game.cjs` で実行できます。問題画像は built-in image_gen で生成しました。日本語フォントのライセンスは `dist/fonts/OFL.txt` に同梱しています。
